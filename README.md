# Karanvir City

Cinematic scroll portfolio for **Karanvir Singh** — MERN Stack / Full-Stack Developer.

## Experience

Full-viewport sections revealed one-by-one on scroll (Home → Experience → Projects → Skills → AI → Performance → Education → Contact), with a game-style HUD and menu.

## Stack

- Next.js · TypeScript · React
- Framer Motion · Tailwind CSS
- Lucide React

## Develop

```bash
nvm use 22
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
